# Precise results width envelopes - 2026-11-04

Added rr_results_advance.c/h and a source-font numeric metric table as a bounded prerequisite to wrapping. Current native rasterized glyph advances lose precision near the supplied source thresholds. This module preserves primary font-unit sums at 15CSSpx/weight 700 using integer 1/64000px ticks and separately returns the outward 1/64px range-width envelope. The existing fallback approx/queen advance metadata is retained. It is not a new painter, character shaper, min-content/auto-min grid solver or float-fit tolerance. The advance field is the model unit/fallback-metadata sum, not a recovered browser pen or proof of an unrounded system fallback advance.

The unchanged staged Orbitron 700 font is byte-identical to the v4 face used by the measured browser fixture. Existing FontTools 4.61.1 extracts hmtx/em/cmap and nonzero GPOS pair metadata; there are no GSUB features in this selected face. The read-only table contains 95 primary codepoints (ASCII except missing caret, plus em dash), two existing fallback advances and 350 rejected nonzero primary pairs. Font binaries/OFL notices and runtime assets are unchanged. No new fonts/system-font files, bitmaps or license substitutions were generated.

The source corpus contains 1119 single-line text-node ranges across the 60 measured observations. C matches all 1119 outward widths exactly, including names, crown prefixes, estimated-time spans and numeric values. The 16W word yields 282.96875px outward width; adding source 26px list padding reproduces the observed 308.96875px min-track evidence. This is not a general auto-minimum solver. Twenty-one multiline/nonrect nodes are explicitly excluded rather than flattened or truncated. Repeated DPR/scroll observations are counted as observations, not 1119 unique strings.

The qualification boundary is explicit. None of these 1119 runs contains a nonzero font kerning pair, so all 350 such pairs return NEEDS_SHAPING instead of applying unqualified adjustments. Leading/trailing/repeated spaces also return NEEDS_SHAPING because CSS collapse/layout context matters. Unsupported/invalid Unicode, missing caret, controls, malformed UTF8 and over-limit 128-codepoint/<512-byte text fail atomically; no '?' substitution. Empty text returns a zero plan. A separate analysis of a simple floor/ceil character-snapping hypothesis disagreed on 213 nodes, commonly by 1/64px. That failed character-position hypothesis and examples are preserved in the reference receipt. Correct aggregate widths do not qualify per-character origins, font-run/fallback precision, glyph raster, line breaking, floats or universal near-fit behavior.
