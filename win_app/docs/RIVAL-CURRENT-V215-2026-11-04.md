# v0.2.15 rival bolt integration - 2026-11-04

Current package, changelog, modular race source and techplan now agree on v0.2.15 rival combat. New explicit rr_rival_current_step prepares the source's nonhoming 21-damage, 750 m/s, 1.5 s PULSE bolt every 0.63 s. It selects the nearest eligible racer in the 0.3 rad forward cone at 15..1125 m (inclusive), estimates lead with 0.9 target velocity, and adds three independent spread draws of +/-0.03 x road.fire before four warm Three mesh UUID draws. It uses the supplied current model-group muzzle matrix, alternating bumper side, inherited nonnegative speed, current paint/HDR metadata, and a read-only zap callback after heat update. Rivals do not emit the player's muzzle flash. No invented seeker/heat/progression behavior is added.

Heat/cooling/recovery and EMP hold use actual source order. Early guards before 6 s, dead, finished and outside race freeze all timers. fireCD clamps at zero, boltCD can become negative; acquisition/cooling still run during shot cooldown. An EMP fireCD hold blocks fire but does not freeze cooling or boltCD. Resource reset clears heat/overheat and accepts the caller's random()*0.5 initial cooldown while preserving side, as current Racer.reset does; it consumes no RNG itself. Caller still owns the entire racer reset and later react draw. Legacy rr_battle_rival_fire and existing pack/run fixtures retain their older captured behavior; no current API is silently selected in production.

Actual browser source captures cover 4,000 frames across fallback/Roadster/Viper/Titan model poses and four paints, all three representative road.fire values, 20 source resets, 166 emitted bolts and 1,202 RNG draws. Traces include target eligibility, minimum/maximum range and cone boundaries, nearest ties, moving targets, negative shooter speed, forced overheat recovery, EMP holds and lifecycle guards. C compares retained state before/after each frame, full emitted initialization/paint/muzzle/velocity and exact RNG state/count; zap callback is checked after heat/side changes. Actual Racer.reset supplies reference reset RNG ordering; supplied matrices use real Three transforms and Car.muzzle. Test resources are reused one shot at a time, so no emissions are dropped to meet a budget. Native and WASM full builds each pass 98/98 CPU tests; see rival-current-implementation.json for exact summaries, numeric errors, hashes and logs.

Resources: a small fixed per-rival resource struct, fixed vector arithmetic, and existing borrowed shot storage. No heap/GPU allocation, resource-cap raise, new texture/model/font/audio asset, or user-store change. All 449 native asset copies match. Earlier client and all current-player-fire files are hash-preserved except the necessary CMake target addition. main.c and device preferences remain unchanged. Source snapshots, docs/techplan/protocol evidence and originals are preserved under reference.
