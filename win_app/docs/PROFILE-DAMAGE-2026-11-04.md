# v0.2.17 race projectile damage reactions

Current full-pack projectile impacts now use the victim's profile knock/stun multipliers. Race damage uses source KNOCK values (bolt speed kept .985 / stun .12; seeker .5 / 1; EMP .65 / 1.6; fallback shot .6 / .7), then keeps speed by 1-min(1,(1-keep)*knock) and raises stun to max(existing,baseStun*profileStun). HP loss stays the incoming amount. Inactive race, finished and wrecked victims reject damage; a rolling victim dodges. Lethal hits clamp HP to zero, hide the car, zero speed/velocity and set wreck to 2.4 seconds; the existing fire host handles lock release, FX and shake.
