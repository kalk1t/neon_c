# 2. Controls

✅ **Done** · [Manual contents](README.md) · Previous: [Getting started](01-getting-started.md) · Next: [Game modes](03-game-modes.md)

The game supports three ways to play. It picks the right one by itself: on a phone or tablet it shows touch buttons,
and as soon as it sees a real mouse or keyboard it switches to those.

## Keyboard and mouse
When a race starts, the game **captures your mouse** (the pointer disappears). Moving the mouse moves an aim dot,
and the car steers and climbs toward it. Press **Esc** to get the pointer back; that also pauses the game. Click the
game to capture the mouse again.

### Flying
| Key | Action |
|---|---|
| **Mouse** | Aim; the view turns with it and the car steers, climbs and dives after the aim ring |
| **W** | Thrust (hold) |
| **S** | Brake; keep holding to fly backwards slowly |
| **Shift** | Boost / nitro (hold) |
| **A / D** | Slide sideways (with the mouse; keyboard only: steer) |
| **← / →** | Steer with keys |
| **↑ / ↓**, **E / Q** | Climb / dive with keys (E climbs, Q dives) |
| **Right mouse button** (hold) | Look around the car; the view swings back when you let go |
| **C** | Change camera: near chase → far chase → first person (in the cockpit view: back to the chase camera) |
| **I** | Cockpit view on / off: fly from inside your car, with its dashboard ([Flying](04-flying.md#cockpit-view)) |
| **R** | Reset: back to your last checkpoint (in FREE ROAM, back to your spawn point) |

### Weapons
| Key | Action |
|---|---|
| **Left mouse button** (hold) or **J** | Pulse blaster |
| **Space** or **middle mouse button** | Seeker missile |
| **X** or **V** | EMP shockwave |
| **F** | Spin dodge |

### Game
| Key | Action |
|---|---|
| **Esc** or **P** | Pause / resume |
| **M** | Mute / unmute |
| **Enter** | On the main menu: start a race. In FREE ROAM: open chat |
| **T** | In FREE ROAM: open chat |

## Phone and tablet
![Phone controls](../media/v0.1/phone-race.jpg)

**Hold the phone sideways like a steering wheel.** The car **accelerates by itself**.

| Control | Action |
|---|---|
| **Tilt left / right** | Steer (about 24° of tilt is full lock) |
| **Tip the top edge toward you / away** | Climb / dive (about 18° is full) |
| **Drag on the left half of the screen** | A joystick, if your phone has no tilt sensor or you prefer it. While you drag, it overrides tilt |
| **BRAKE** (bottom left) | Brake (stops the automatic acceleration) |
| **BOOST** (bottom right, large) | Boost (hold) |
| **FIRE** | Pulse blaster (hold) |
| **SEEKER** | Seeker missile |
| **EMP** | EMP shockwave |
| **SPIN** | Spin dodge |
| **II** (top) | Pause |
| **◎ TILT** (top) | Re-level: the way you hold the phone now becomes "flying level" |
| **CHAT** (top, FREE ROAM only) | Open chat with the phone keyboard |
| **VIEW** (top, next to the map) | Cockpit view on / off (pink while you're inside) |

Tips:
- Hold the phone at a comfortable angle when the race starts. The game takes that angle as level flight. If the car
  keeps climbing or diving, tap **◎ TILT**.
- **INVERT Y** on the menu swaps climb and dive for tilt too.
- Phones start on **LOW** graphics for a smoother frame rate.

## Gamepad
Any standard controller (Xbox layout shown) works once you press a button.

| Control | Action |
|---|---|
| **Left stick** | Steer and climb/dive |
| **RT** (right trigger) | Thrust |
| **LT** (left trigger) | Brake |
| **A** | Boost |
| **RB** | Pulse blaster (hold) |
| **X** | Seeker missile |
| **B** | Spin dodge |
| **LB** | EMP |
| **Y** | Change camera (the cockpit view has no gamepad button yet: press **I** on the keyboard) |
| **Back / View** | Reset |
| **Start / Menu** | Pause |

## Mouse settings
**MOUSE SENS** (0.3 to 2.5) and **INVERT Y** are on the main menu; see [Settings](08-settings.md).
