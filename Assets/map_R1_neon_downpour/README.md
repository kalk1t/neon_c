# R1 — Neon Downpour

**Individual asset references and a Claude implementation kit for the selected rainy flying-car racing map.**

A rain-soaked night city with dark glass towers, cyan facade ribs, restrained magenta accents, elevated wet decks, a monumental twin-tower skybridge and a lower canal.

Open **START_HERE.html** for the visual asset gallery. Give Claude **CLAUDE_START_HERE.md** and this whole folder in the actual game workspace.

## Contents

- 27 individual PNG items: 12 common course references, 3 neutral weather sprites and 12 map-specific environment references.
- Original selected scene, exact image prompts and per-item modeling specifications.
- Authored closed-loop route, placement data and route diagrams.
- Blender source kit for procedural blockout creation, with a source-data validator.
- Blender/Meshy, materials/weather, game integration and validation guides.
- Asset catalog, empty Meshy task ledger and package QA/integrity records.

## Delivery status

The PNGs and documentation are supplied; the route is a newly authored proposal inspired by the chosen scene. **Production 3D meshes, .blend files and game integration still need to be built by Claude.** No Meshy credits were spent and Blender was not available for execution here.

The exact proposed route dimensions and validation result are in Layout/validation_report.json. Item sizes/LOD budgets are construction targets, not measurements of generated meshes. The source kit's own documentation identifies what it creates.

Cyan tower; stepped tower; twin-tower skybridge; midrise block; rooftop platform; canal wall; canal bridge; roof vent; antenna; blank billboard; energy cabinet; distant skyline cluster.
